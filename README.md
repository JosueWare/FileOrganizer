# File Organizer
O **FileOrganizer** faz que os arquivos todos bagunçados em uma determinada pasta sejam separados em cada pastas de tipos de arquivos, seja Fotos, Vídeos, GIFs, Documentos e etc. Utilizando o PowerShell para automações.

Antes de começar usar siga os passo a passo.

1. Execute primeiramente o arquivo `Run.bat` pois a pasta "Media" não existe e ela será criada automaticamente.
2. Pegue seus arquivos bagunçados e jogue na pasta "Media".
3. Com o Terminal aberto haverá uma questão se você deseja iniciar, digite "S".
4. Seus arquivos serão tudo organizados em cada pastas pessoais do sistema, todas nomeadas como "**FileOrganizer**".

**AVISO:**
- Não há suporte para o Windows PowerShell, você deve utilizar o PowerShell 7 para prosseguir.

O Script possui suporte a diversas extensões de arquivos, incluindo: 

- Imagens:
  - PNG
  - JPG
  - JPEG
  - GIF
  - BMP
  - SVG
  - WEBP
  - AVIF
  - APNG
  - RAW
- Vídeos:
  - MP4
  - MKV
- Documentos:
  - TXT
  - MD (Markdown)
